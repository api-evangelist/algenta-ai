Algenta — Self-Hosted Building Blocks for AI Applications. Algenta provides a deterministic runtime and SDK for AI agents, offering simulation, decision planning, memory, and governed execution on CPUs, Apple Metal, and NVIDIA GPUs. It supports self-hosted deployment, air-gapped mode, and integrates with popular frameworks like LangChain and LlamaIndex.

**Areas:** AI · Self-hosted · Deterministic · Platform · SDK

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Algenta: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
